# 같은 5시리즈, 다른 탄소

**BMW 5시리즈 전과정평가(LCA)와 Scope 3·회피배출 적용 사례**

🔗 **웹페이지: https://goalbangg-prog.github.io/BMW-5-series-LCA/** (PC 화면에 맞춰 제작)

BMW 5시리즈 다섯 차종이 만들어져 폐차될 때까지 배출하는 온실가스를 **한국 주행 조건**으로 다시 계산했습니다. 그 결과를 수입·판매사인 **BMW 코리아의 Scope 3 산정**과 **회피배출 분석**까지 이었습니다. 웹 계산기에서 주행거리, 충전 전력, 충전 습관을 바꾸면 Scope 3와 회피배출 숫자도 함께 다시 계산됩니다.

> 공개자료로 수행한 개인 분석입니다. 인증된 EPD, 제3자 검증을 받은 제품 탄소발자국(PCF), 회사의 공식 Scope 3 인벤토리가 아니며, Scope 3와 회피배출은 방법을 보여주기 위한 예시입니다.

## 왜 이 분석을 했나

1. **BMW가 공개한 LCA는 유럽 조건입니다.** 유럽 전력과 유럽 시험 연비를 기준으로 하므로, 한국 전력과 국내 공인 연비로 다시 계산하면 결과가 달라집니다.
2. **제품 LCA와 기업 공시는 따로 다뤄지기 쉽습니다.** 차 한 대의 LCA 결과가 수입사의 Scope 3 항목으로 어떻게 나뉘고, "전기차로 탄소를 줄였다"는 회피배출 주장이 언제 성립하는지를 한 흐름으로 보여주고자 했습니다.

## 핵심 결과

기본 조건: 한국 전력 2021년 값 고정(국가 LCI DB), 20만 km, PHEV 전기 주행 비율 45.5%

| 차종 | 생애주기 배출 (tCO₂eq) | 1 km당 (g) |
|---|---:|---:|
| 520i (가솔린) | 56.7 | 283 |
| 530e (PHEV) | 56.1 | 280 |
| i5 eDrive40 (전기) | **40.6** | 203 |
| M5 (PHEV) | 69.6 | 348 |
| i5 M60 (전기) | **45.5** | 228 |

- **제품:** i5 eDrive40은 520i보다 28% 적게 배출합니다. 배터리 제조로 5.9 tCO₂eq를 더 배출하지만 약 5.4만 km를 달리면 만회합니다. 순위가 뒤집히려면 전력 배출계수가 0.90 kg/kWh를 넘어야 합니다(이 분석은 0.53).
- **충전 습관:** 530e는 충전 없이 타면 63.0 tCO₂eq로 520i보다 11% 많이 배출합니다. BMW 보고서의 WLTP 기준 전기 주행 비율 90% 대신 유럽 실측 45.5%를 적용하면 49.4 tCO₂eq → 56.1 tCO₂eq로 늘어납니다.
- **Scope 3 (예시 산정):** BMW 코리아 기준으로 차량 제조 전체가 Cat 1, 출고 운송이 Cat 4, 사용이 Cat 11, 폐차가 Cat 12입니다. 2025년 상반기 5시리즈 판매분(모델링한 3종 9,456대)의 Cat 11 필수 범위는 약 31.5만 tCO₂eq로 산정 합계의 72%입니다.
- **회피배출 (예시 산정):** 같은 기간 i5 828대의 회피배출은 "i5가 없었다면 대신 샀을 같은 5시리즈"에 따라 약 1.3만~1.7만 tCO₂eq입니다(530e 12,841 · 520i 13,339 · 530i xDrive 17,343 tCO₂eq). i5와 같은 가격대인 530e 기준이 가장 보수적인 값이며, WBCSD 지침에 따라 Scope 3에서 빼지 않고 따로 보고해야 합니다.
- **민감도:** 가정을 하나씩 가장 불리한 값까지 바꿔도 i5 eDrive40이 520i보다 1대당 7.3~27.1 tCO₂eq 적게 배출해, 결론이 유지됩니다.

## 수행 내용

| 단계 | 한 일 |
|---|---|
| 목표·범위 정의 | ISO 14044 항목(적용 목적, 기능단위, 기준흐름, 시스템 경계, 컷오프, 할당, 데이터 품질 요구사항 등) 18개를 정의 |
| 배경 데이터 처리 | 국가 LCI DB 데이터셋을 ILCD 형식으로 내려받아 대기 배출 원소 흐름(CO₂·CH₄·N₂O 등)에 IPCC 6차 보고서 값을 곱해 다시 계산 |
| 사용 단계 모델링 | 국내 공인 연비·전비로 차종별 기준흐름(휘발유 L, 전기 kWh)을 계산하고 2006 IPCC 연소 계수와 국내 순발열량을 적용 |
| 전력 시나리오 | 2021년 데이터셋 값을 출발점으로, 제11차 전력수급기본계획의 발전 비중 변화 비율을 곱해 2025~2039년 계수를 산출 |
| Scope 3 산정 | 수입사 기준으로 Cat 1·4·11·12를 나누고, Cat 11은 필수 범위(배기·충전 전기)와 선택 범위(연료·전기 생산)를 구분 |
| 회피배출 분석 | WBCSD 3가지 조건(회사·제품·기여)을 점검하고, 대신 샀을 차 3가지(같은 가격대 530e·530i xDrive, 기본형 520i)와 비교해 범위로 산정 |
| 민감도 분석 | 주행거리, 실제 연비, 충전 전력, 배터리 제조 배출 등 11개 가정을 하나씩 바꿔 결론 유지 여부 확인 |
| 데이터 품질 관리 | 입력값 16개에 자료 유형·검증 상태·대표성(시간·지역·기술)을 기록하고, 찾았지만 쓰지 않은 데이터 4건과 이유를 남김 |
| 웹 구현 | Python 모델과 같은 식을 JavaScript로 옮겨 조건을 바꾸면 모든 숫자가 다시 계산되는 계산기를 제작 |

## 분석 중 판단한 것

| 쟁점 | 선택 | 이유 |
|---|---|---|
| 국가 LCI DB 데이터셋의 표시값을 그대로 쓸지 | 원소 흐름으로 다시 계산 | 휘발유 표시값(0.917 kg/kg)은 유럽 EF 방식이고 100년 이후 장기 배출(0.125)까지 포함합니다. ISO 14067 기준으로 맞추면 0.792 kg/kg입니다 |
| LCA에 쓸 전력 계수 | 국가 LCI DB 2021년 데이터셋 그대로 (0.529 kg/kWh) | DB에 있는 소비 믹스 값이 이것뿐이고, 최신값보다 높아 전기차에 불리한(보수적인) 방향입니다 |
| Scope 3 Cat 11에 쓸 전력 계수 | 2023년 국가 전력배출계수 (0.4173 kg/kWh) | 2025년 판매분을 보고하는 시점의 최신 공표값이라 공시용으로 따로 적용했습니다 |
| 수입사의 Cat 1 범위 | 공장 배출까지 포함한 차량 전체 | BMW 그룹의 Scope 1·2(공장 배출)도 BMW 코리아 입장에서는 구매한 제품의 배출입니다 |
| 자동차운반선 해상운송 데이터셋 | 쓰지 않음 | BMW 제조 값의 물류에 이미 출고 운송이 포함되어 있어 더하면 이중 계산입니다 |
| 발전원별 전력 데이터셋 합산 | 쓰지 않음 | 2023년 비중으로 합치면 생산 믹스 데이터셋보다 약 20% 높고, 원인을 확인하지 못했습니다 |
| 회피배출 비교 기준 | 같은 5시리즈 3종: i5와 같은 가격대(530e 8,920만~·530i xDrive 9,020만 원)와 기본형 520i | 520i는 i5보다 약 2,500만 원 저렴해 대안으로 약해, 가격대가 같은 차를 함께 두었습니다. 경쟁사(벤츠 E클래스, 제네시스 G80)는 국내 판매 차종의 제조사 LCA가 공개되지 않아(벤츠는 국내 미판매 E 300 e만 공개) 추정을 피하려고 정량 비교에서 뺐습니다 |
| M5·i5 M60 제조 배출 | 세 차종에서 역산한 계수로 추정 | BMW가 두 차종의 LCA를 공개하지 않았습니다. 추정임을 화면에 표시했습니다 |

## 한계

- 온실가스 배출량만 산정했습니다. 다른 환경 영향은 다루지 않았습니다.
- 제조 단계는 BMW가 공개한 결과값을 인용했습니다. 직접 모델링한 부분은 연료·전기 생산과 주행 배출입니다. M5·i5 M60 제조 배출은 추정입니다.
- 국가 LCI DB 데이터셋은 2020~2022년 자료이고, 전력은 2021년 값이라 전기차에 다소 불리하게 계산됐을 수 있습니다.
- 폐차는 BMW 자료대로 세 차종 모두 0.6 tCO₂eq이며, 큰 배터리의 해체·재활용 부담 차이는 반영하지 못했습니다.
- 충전 습관은 국내 통계가 없어 유럽 자료를 썼습니다.
- 530i xDrive의 제조 배출은 BMW가 공개하지 않아, 같은 차체·같은 2.0 가솔린 계열인 520i의 공개값을 무게 비율로 보정했습니다. i5 구매자 중 원래 다른 전기차를 사려던 사람이 있다면 회피배출은 더 작아집니다.
- Scope 3는 BMW 코리아의 실제 운임 부담 조건과 트림별 판매 대수를 모르는 상태의 예시입니다.
- 공개 비교를 하는 LCA는 ISO 14044상 외부 전문가 검토 대상이지만, 이 분석은 검토를 받지 않았습니다.

## 폴더 구성

```
index.html                 # 웹페이지 (GitHub Pages)
img/                       # 차량 이미지
data/vehicles.csv          # 차종별 입력값과 출처

web/index.template.html    # 웹페이지 원본
web/build.py               # results.json을 템플릿에 넣어 index.html 생성
```

## 다시 실행하기

```bash
pip install numpy pandas
python analysis/lca_model.py   # outputs/ 생성
python web/build.py            # index.html 생성
```
